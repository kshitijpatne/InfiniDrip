## Exit record

### Findings — duplicate path identity is direct; coherent assembly is not

- **Exact current matrix:** the S356 retained production-derived SVG matrix contains 28 Woven option configurations and 56 front/back faces at `live-draft:woven-shirt:14:14`. Production code affecting these outputs did not change in S357. S358 parsed the current same-revision paths for `outerStand`, `upperCollar`, `underCollar`, and `innerStand`; the latter remains intentionally hidden by the admitted face map. Every record preserves its `pattern:woven-shirt:role:<id>` identity and `GARMENT_SILHOUETTE` layer.
- **Directly encoded geometry/stitches:** `src/drafting/shirt.ts` builds `outerStand` and `innerStand` from the same `standPiece(necklineLength, standHeight)` function and builds `upperCollar` and `underCollar` from the same `collarPiece(necklineLength, collarLeafDepth)` function. The source stitches join `underCollar.stand` to `outerStand.collar`, `upperCollar.stand` to `innerStand.collar`, and `upperCollar.frontTip + upperCollar.outer` to the matching `underCollar.frontTip + underCollar.outer`. The source-defined outer pair is therefore sewn around matching edge runs; no separate turn-of-cloth, visible-layer split or upper/under face instance is authored.
- **Exact rendered duplicate:** all 56 SVGs contain two outline paths per visible upper- and under-collar source role (one source half plus the on-fold reflection). The path data arrays for `upperCollar` and `underCollar` are byte-equal on every face. Both map to the same `GARMENT_SILHOUETTE` layer as visible overlays. The existing renderer draws duplicate source identities over one another; it does not create a visible double-thickness line. S321's approved CB-to-CF exterior transfer applies to both roles and remains intact. Hiding one role or assigning one an invented turnback/layer offset would be a new view decision, not a source-derived correction.
- **Source/assembly residual blocker:** for the standard default configuration, the retained S347 exact transform audit gives the same rigid placement for `outerStand`, `upperCollar`, and `underCollar` on the front: offset `(21.139570204354, -5.510094044767) cm`, rotation `141.34019174591°`; on the back: offset `(-0.976405743549, 0.757845095837) cm`, rotation `-16.699244233994°`. The outer stand's source neckline is a straight edge, whereas the body front/yoke neckline is curved. S343's approved display correctly shows the source body neckline as the sole base seam and suppresses the stand-base duplicate, but this changes only stroke identity; it does not make the collar assembly coherent.
- **Actual inspected output:** S358 produced color-coded role overlays from the S356 production-derived candidates at the exact same revision. Default front/back, stand-height min/max front, collar-leaf-depth min front/max front, and yoke-depth min/max back were inspected. On the front, the collar/stand assembly remains a detached angular island over the chest/placket region; collar, closure and existing callout geometry collide. On the back, the neck stand/collar lines lie across the yoke/body boundary and intersect the neckline/yoke geometry; the POM label/leader is close to the seam. These outputs are diagnostic candidates; they are not accepted flats and do not release a hold. The retained PNGs and inventory preserve the inspected evidence.
- **What duplicate suppression can and cannot do:** removing a repeated `upperCollar` or `underCollar` path would leave the same visible stroke at the same coordinates, so it would not resolve the detached/crossed collar placement or distinguish the physical face of the layered collar. The output already displays the body neckline only under S343. No additional stroke-suppression implementation is justified by this evidence.
- **Evidence classifications:** piece construction and source stitch references above are **directly encoded in pattern source**; the current overlap/transform/crossing statements are **measured from exact-revision emitted paths and rendered overlays**; assigning upper/under visibility, a turnback boundary, or a different collar placement would be a **proposed design decision** not authorized here. S288/S294/S323 and S342/S343 were reviewed; their pattern-specific sources support the existing exterior station and base-seam decisions but do not settle the remaining physical face/layer or rigid-assembly discrepancy. No new broad source search was run because no unchecked specific source was identified.
