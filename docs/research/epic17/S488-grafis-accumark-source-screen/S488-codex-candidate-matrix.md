# S488 — GRAFIS and Gerber AccuMark source matrix

Reviewed 2026-10-08 using official GRAFIS and Lectra/Gerber sources only. The
question is a no-cost local receiver for V03; a feature claim alone is not a
receiver qualification or round-trip result.

## Candidate A — GRAFIS training version

| Gate | Evidence and disposition |
|---|---|
| No-cost rights | **No-cost but tightly restricted.** The publisher's training-version page calls it free/gratuitous, for private training and evaluation/practice; it excludes commercial or freelancer activity. The contract page itself lists conflicting license end dates (2023 in §3, 2027 in §2); this is recorded, not reconciled. |
| Windows 11 | **Supported for the training version.** Its agreement says Windows 10 or 11. |
| Local handling | **Local desktop installer is described**, but the page makes clear this does not solve the exchange need. No assertion of local-only processing for a full license is made. |
| Apparel-profile input/output | **Fails for the free training version.** Publisher says import/export, plotting, and output are disabled in this edition. The commercial-system FAQ says its import/export module is not included in every standard package and may need to be purchased separately; its help documents AAMA/DXF and ASTM/DXF export options. Those capabilities cannot be used in the free edition. |
| Round-trip/profile | **Not testable in the free edition.** No same-receiver trial can establish exchange when that edition disables both directions. |
| Grade/negative behavior | Training version limits models to 20 parts/10 sizes; no AAMA/ASTM grading interchange or malformed-input behavior is established for it. |
| Decision | **Not qualified as a V03 receiver under the no-cost constraint.** The free edition is useful for private learning/evaluation only and disables the needed exchange. Full-version access is licensed/rented; its exchange module may be separately chargeable. No free exchange-capable tier was found in the reviewed official sources. |

Primary sources: [GRAFIS training version and agreement](https://www.grafis.com/training-version), [GRAFIS FAQ](https://grafis.com/faqs), and [GRAFIS sales FAQ](https://www.grafis.com/faq-sales). The FAQ currently serves German exchange-format text; no translation is used to enlarge the claims beyond its explicit direct-import/export and simple-DXF statements.

## Candidate B — Gerber AccuMark

| Gate | Evidence and disposition |
|---|---|
| No-cost rights | **Not established; the user's no-paid-software preference is unmet on this evidence.** Lectra describes a subscription route with an annual fee; official licensing docs require assigned, valid product access. The reviewed sources disclose no no-cost trial or free licensed path, but do not establish that no such exception could exist. Do not download/install or spend. |
| Windows 11 | **Supported only on qualifying versions/configurations.** Official help says Windows 11 support begins with AccuMark V15 and lists 64-bit Professional or Enterprise editions; Windows 11 Home is listed unsupported. Host edition and exact accessible build are unverified. The product page lists V2026.1, but the older detailed file-help page does not bind its behavior to that exact build. |
| Local handling | **Unresolved.** Help describes opening/converting files through Pattern Design and saving format exports, but does not establish that every relevant processing step is local-only. License validation requires account/email, USB key, or network license. |
| Apparel-profile input | **Advertised/documented in official help.** AccuMark Pattern Design opens/converts ASTM/AAMA, TIIP, standard DXF and other CAD inputs. |
| Apparel-profile output | **Advertised/documented in official help.** It can save models as ASTM/AAMA DXF; pieces may also use Standard DXF or IGS. |
| Round-trip/profile | **Capability path is documented, evidence is not.** Import and export directions exist, but there is no exact-build InfiniDrip fixture, observed local round-trip, profile field/layer evidence, or receiver acceptance. |
| Grade/negative behavior | Product documentation identifies grading and model/rule-table functions, but the reviewed sources do not establish our representative fixture's size-rule fidelity or malformed-input behavior. |
| Decision | **Potential technical receiver, not currently actionable.** Stronger documented apparel-profile directionality than generic CAD, but no documented no-cost access, exact-build access, local-only assurance, or actual round-trip evidence. |

Primary sources: [AccuMark Pattern Design open/import help](https://help.gerbertechnology.com/AccuMark/PDS/File_Open_Tab_File.htm), [export help](https://help.gerbertechnology.com/accumark/PDS/File_Export_Tab_File.htm), [Windows configuration](https://help.gerbertechnology.com/AccuMark/Recommended_Configuration_2D.htm), [current product page](https://www.lectra.com/en/fashion/products/gerber-accumark-fashion), [subscription terms overview](https://www.lectra.com/en/library/why-you-should-switch-to-modaris-and-gerber-accumark-software-subscriptions), and [licensed product downloads/authentication](https://gerber-help.lectra.com/Licensing/Downloads.htm).

## Conclusion

Neither candidate clears the present no-cost local receiver requirement.
GRAFIS's free Windows 10/11 training version expressly disables import/export;
the commercial system's format documentation cannot be transferred to that
edition. AccuMark documents both ASTM/AAMA import and export and supports
Windows 11 on supported editions/builds, but the official material describes
licensed/subscription access and provides no qualifying free trial. No
software or fixture was used. Keep V03 rights, local-handling, exact-build,
round-trip, grading, and malformed-input gates unchanged.
