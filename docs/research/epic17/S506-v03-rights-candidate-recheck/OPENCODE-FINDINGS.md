### 1.3 Rights question (a): permission for a noncommercial local evaluation of InfiniDrip's product-development DXF test

Unestablished. No specific official Richpeace license, evaluation agreement, terms-of-use page, or support page found in this audit grants, scopes, or denies permission for this exact use. The only rights-adjacent official wording is the product-page marketing sentence quoted above (`Full function evaluation copy ... welcomed to try on ... no limitation set ...`). That sentence:

- does not name permitted users, permitted purposes, commercial vs. noncommercial use, product-development use, evaluation duration, seat/transfer limits, or restrictions;
- uses `no limitation set` in the same sentence as DGS pattern functions (`create, save and print any pattern designs ... pattern gradinig`), so it reads as a functional-marketing claim, not a license grant, and this audit does not interpret it as an unlimited rights grant;
- is ambiguous precisely because `evaluation copy` is stated without any linked or displayed evaluation terms.

Therefore absence of a found restriction is not permission, and the marketing sentence is not an affirmative grant. Gate 0 remains unestablished for V8 Free English on current official evidence.

### 1.4 Locality question (b): does ordinary import/export stay on-device or go to a service?

Unestablished. No official V8 Free English page or document inspected here describes the data path for ordinary file open/import/export: no statement that files remain on-device, and no statement that they are uploaded, converted remotely, or otherwise sent to a service. The V8 Free product and download pages contain no cloud/local wording at all. Cloud wording found on the site belongs to separately named products and must not be transferred to V8 Free:

- `Richpeace Garment CAD Super V8` (https://www.richpeace.com/garment_cad-show-751.html, System `WIN7/8/10`) discloses `Using Richpeace cloud computing technology` for auto-marker and a `cloud conversion function ... for free for a limited time`.

Those disclosures prove only that some other Richpeace offerings use hosted processing; they say nothing about V8 Free English's ordinary DXF handling. No publisher privacy/data-handling statement for desktop CAD file processing was found on `www.richpeace.com` in this audit.

## 4. Ambiguous official-document text (do not resolve by inference)

1. V8 `Full function evaluation copy ... welcomed to try on` + `no limitation set`: marketing language without a linked agreement. Ambiguous whether `no limitation` means functional parity with paid V8, unlimited time, unlimited purpose, or only the listed DGS/GMS pattern functions. Not a rights grant.
2. V8/V10 `System Windows XP/7/8/10` (V10 with duplicated `System` label): ambiguous whether later Windows is merely untested or unsupported. Either way Windows 11 is not listed; do not assume support.
3. V10 `Import other formats such as DXF, AAMA/ASTM/AUTOCAD`: ambiguous whether `AUTOCAD` means generic AutoCAD DXF, which DXF versions/encodings, which AAMA/ASTM profile or year, and whether `such as` is exhaustive. Import-only in any case.
4. V10 portal title/binary mismatch (`Richpeace Garment CAD V10.0` + `20220919RPCAD_Enterprise_V10.rar` vs. product-page `(demo) Free`): ambiguous whether the portal record describes the demo edition. Do not use the portal binary name as edition evidence.
5. Super V8 `genuine free` / `free ... for a limited time` (cloud conversion) and Cloud Super Nest timed charging: ambiguous only if misread as applying to V8/V10. They are separate product disclosures and must not be transferred.
