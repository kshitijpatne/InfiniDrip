# S321 exact pattern topology overlays

These are annotated drawings of exact recipe drafts at `STANDARD_M`, generated
from source commit `5e03d371dc0986a95e4472bd642d63b07d201468` (Slice 320).
The JSON files retain role edge endpoints, marks, recipe options and stitch
interfaces. SVG and PNG files show each physical pattern role separately in
its authored local coordinates. There are no assembly transforms and no
pattern or cut geometry changes.

Orange annotations are proposals only: the sleeve crown-to-hem split has no
source mark; collar stations on an exterior edge that has no shoulder join use
the proposed normalized CB-to-CF arclength transfer. The Polo outer-stand
shoulder is instead the exact shared endpoint of `backCollar` and
`frontCollar`. Violet marks and dashed lines are drafted pattern marks.

The artifacts do not claim a completed technical flat, face orientation,
instance count, sew order, closure overlap, or accepted output. The source and
decision ledger in `../G04-V02-SOURCE-MAPPING-PROPOSALS-S321.md` explains each
annotation and its limits. Read the PNGs for quick inspection and the JSON for
exact coordinates and edge identities.
