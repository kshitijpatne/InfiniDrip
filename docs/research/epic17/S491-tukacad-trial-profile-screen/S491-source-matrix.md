## Candidate decision

Do not select the free trial as the V03 receiver on this evidence. The named
CLE plan does not list import/export; current public material does not say its
14-day trial unlocks the CPE exchange feature. The tutorial's legacy artwork
import is insufficient for pattern exchange. Rights for local product-
development evaluation and local file handling remain unproven, and no
account-specific grant was inspected. The lead is rejected as currently
documented, with these unknowns preserved rather than guessed.
