### POM source mapping audit

The exact source methods are in `src/drafting/tshirt-pom.ts`, `src/drafting/polo.ts` (`POLO_POMS`), and `src/drafting/recipe.ts` (`POLO.poms`). Four front POMs currently have callouts to the same-revision `front` outline: body chest → `front.side.start`; across shoulder → `front.shoulder.end`; neck width → `front.shoulder.start`; front neck drop → `front.neckline.start`. These are exact authored vertices, but their current single-point anchors do not encode all endpoints of the measured dimensions. The source renderer currently supports only one mapped body anchor role for Polo and does not expose a general per-callout target role or paired endpoint dimension contract.

The remaining source geometry is explicit; the following is a proposed mapping for a later bounded implementation slice, not implemented in S337:

| POM | Exact source geometry to bind | Front/back instances and practical rendering |
|---|---|---|
| Shoulder seam | `front.shoulder` / `back.shoulder` edge | One edge-length leader on each face; both edges are directly encoded. |
| Armhole (front + back) | `front.armhole` and `back.armhole` edges | Identify both summed edges on both flats; do not collapse into one arbitrary edge. |
| Sleeve length (cap–hem) | `sleeve.capLeft.end` to `sleeve.hem.start` | Bind both endpoints to the respective front-view sleeve instance; duplicate for back-view sleeve instance. |
| Sleeve bicep width | `sleeve.sideLeft.end` to `sleeve.sideRight.start` | Two exact endpoints on the face's sleeve instance, front and back. |
| Sleeve hem | `sleeve.hem` edge | Edge-length leader on each face's sleeve instance. |

The proposed renderer needs same-revision source-reference resolution for per-callout role/edge/mark identity and for one- or two-point anchors. Table values stay available when a face does not represent the relevant source; they must not be given a misleading leader. The center-back fold edge and the back-hem-drop comparison are special cases: the exact measurement references are encoded, but the exterior face map either excludes the fold edge or does not show both body hem references together. Any annotation that projects a hidden reference into the face is a proposed view convention and needs explicit maintainer choice unless the current annotation system can display it as a non-garment dimension without implying an authored seam. Exact placement, collision and readability still require generated output review before any affected face can pass.
