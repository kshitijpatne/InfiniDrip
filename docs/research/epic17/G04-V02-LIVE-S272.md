## Exit evidence

### Implementation

The advanced **Technical flat** canvas view now selects Front or Back and
composes the selected face synchronously from the active recipe, exact pattern
block, current raw supported options, saved artwork placements, fabric
appearance and one live draft revision token. The UI says that token is a live
draft and not saved style history. Unsupported option values, an unavailable
pattern size, unresolved role assembly and unreadable measured SVG return
visible correction/status text and no partial face. Face changes and pattern
edits refresh the drawing while preserving the active recipe snapshot.

The canvas fits flat sheets to its available width and scrolls tall drawings
vertically. This keeps browser text at a readable screen size without changing
the SVG's centimetre coordinates. SVGs now include a white paper surface for
dark-app contrast; the selected colorway remains revision-bound metadata and is
drawn as a light fabric tint so dark colors do not hide technical linework.
Neither presentation change affects generic DXF or other exports.
