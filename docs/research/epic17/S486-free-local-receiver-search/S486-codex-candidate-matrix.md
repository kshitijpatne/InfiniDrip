# S486 — Codex candidate evidence matrix

Checked 2026-10-08 against publisher/project sources. The bounded search
evaluated three new receiver candidates: iDigit Lite, Fashion Dot Tailoring
CAD, and Wild Ginger Cameo v8. Unknown means open, not passed. This matrix
does not select a receiver or change V03/C04 acceptance.

## Candidate 1 — iDigit Lite

| Gate | Evidence and disposition |
|---|---|
| Rights / free access | **Open; free access not shown.** Publisher describes a software-plus-digitizing-board system; no free license or evaluation grant was found. |
| Windows 11 | **Open.** Reviewed product pages do not name a supported Windows version. |
| Local-only handling | **Open.** Product is presented as software with an optional camera and physical board, but no exact processing/data-handling statement establishes local-only file operations. |
| Apparel DXF input | **Open.** Main page says existing digital patterns can be imported without naming DXF or the importer. Its workflow instead says to export DXF and import that DXF into separate grading software; this does not prove iDigit itself receives apparel DXF. |
| Apparel DXF output | **Advertised.** Publisher says iDigit Lite exports AAMA DXF and general DXF with customizable layers. |
| Round-trip/profile | **Open.** No exact profile/layer specification, same-tool reimport, or round-trip fixture results were found. |
| Grade / negative behavior | **Not established.** Publisher workflow hands DXF to external grading software; no DXF grading or malformed-input behavior for iDigit is documented. |
| Decision | Not qualified. It is an apparel digitizer/output tool, but rights, Windows 11, local handling, and DXF reception remain unproven. |

Primary sources: [iDigit apparel digitizing product page](https://www.i-digit.co.uk/apparel-pattern-digitizing) and [iDigit Lite product page](https://www.i-digit.co.uk/idigit-lite).

## Candidate 2 — Fashion Dot Tailoring CAD

| Gate | Evidence and disposition |
|---|---|
| Rights / free access | **Fails no-cost preference.** Publisher says it is bought once, with lifetime updates; no free license or trial is documented on the reviewed page. |
| Windows 11 | **Advertised.** Publisher states Windows 10 or 11. |
| Local-only handling | **Open.** Publisher says software is installed on the customer's machine and each license covers one computer, but does not state that exchange-file processing is local-only. |
| Apparel DXF input | **Fails evidence gate.** Body-measurement import is advertised, but no apparel-pattern DXF import is documented. |
| Apparel DXF output | **Advertised generic output.** Publisher lists DXF among outputs, but does not specify AAMA/ASTM or a profile/layer contract. |
| Round-trip/profile | **Open/fails current receiver criteria.** No apparel DXF input, profile, or import/export round-trip evidence. |
| Grade / negative behavior | **Partial native drafting only.** Publisher describes grading from one draft; it does not establish grading in DXF or invalid-file behavior. |
| Decision | Do not pursue under the no-cost preference or as a V03 receiver. |

Primary sources: [Fashion Dot tailoring CAD product page](https://www.fashiondot.in/tailoring-cad-software) and [publisher's tailoring software page](https://www.fashiondot.in/tailoring-software-india).

## Candidate 3 — Wild Ginger Cameo v8

| Gate | Evidence and disposition |
|---|---|
| Rights / free access | **Fails no-cost gate.** Publisher prices Pattern Design, Grading, and Made to Fit at US$950 each; it offers a free demo, not an identified no-cost production license. |
| Windows 11 | **Open.** The publisher identifies Cameo v8 and Windows-based printing, but the pages reviewed do not state Windows 11 support. |
| Local-only handling | **Open.** It is desktop apparel CAD; exact local-only exchange-file handling is not documented on the reviewed pages. |
| Apparel DXF input | **Advertised generic input.** Publisher documents import of standard AutoCAD DXF, but does not identify AAMA/ASTM apparel-profile input. |
| Apparel DXF output | **Advertised generic output.** Publisher documents export of standard AutoCAD DXF, but not AAMA/ASTM. |
| Round-trip/profile | **Fails profile gate.** Generic DXF import/export is documented. Publisher expressly says compatibility with other systems may vary and advises checking the receiving manufacturer's import capabilities. No apparel profile, units/layers, or InfiniDrip fixture round trip is documented. |
| Grade / negative behavior | **Partial native grading only.** A paid grading module is listed; no DXF grade-rule behavior or malformed-input evidence is documented. |
| Decision | Do not pursue as a free V03 receiver. The published generic DXF path is insufficient even apart from price and Windows 11/local-handling gaps. |

Primary sources: [Cameo v8 product/pricing page](https://www.wildginger.com/cameo/default.htm) and [Cameo import/export documentation](https://www.wildginger.com/cameo/cameoexport.htm).

## Existing lead reconciliation

Valentina is not a new S486 candidate: S460 already recorded it as an outbound
DXF lead without demonstrated receiving. The current publisher FAQ strengthens
that disposition: it explicitly says Valentina cannot import a DXF pattern.
It can remain a potential free pattern-drafting/export reference, but cannot
act as this Epic's round-trip receiver. See S460 and the [publisher FAQ](https://smart-pattern.com.ua/en/faq/).

## Conclusion

None of the three new receiver candidates clears the combined rights,
Windows 11, local handling, apparel-profile input/output, representative
round-trip, grade, and negative-input gates. iDigit Lite and Fashion Dot do
not establish apparel DXF reception; Cameo documents only generic AutoCAD DXF,
is paid, and does not establish Windows 11 or local-only file processing. Do
not download/install any of them or weaken a V03 gate on this evidence. Reuse
S463 fixtures only after a candidate independently passes rights, exact-build,
local-handling, and profile preflight.

The remaining dependency is access to an exact, lawful Windows 11 apparel-CAD
receiver that can locally import and export a documented apparel profile.
No production, factory-acceptance, or physical-fit claim is made.
