## Result

`src/render/technical-flat-svg.ts` emits the shared semantic layers in order and keeps each source entity's stable ID, feature, source class, source ID and revision in SVG data attributes. The SVG width and height use centimetres; its viewBox includes the full primitive bounds plus browser-measured label extents. The active browser's SVG text engine measures the same family and font size in the same user-unit scale, and a sample comparison between the returned text bounds and rendered browser `getBBox()` stayed within 0.008 cm. Overlapping labels, labels over artwork placement boundaries and POM leaders crossing other labels return a blocking issue instead of an unreadable SVG. Invalid source/revision views, colorway revision mismatches and unavailable font metrics also withhold output.

Pattern marks use explicit point glyphs; fold marks use a dashed line. POM callouts retain their geometry target and leader. The renderer depicts artwork as a dashed placement boundary because the semantic primitive does not contain image bytes. An explicit, visible notice says that the image content is not embedded, even when the style references an asset ID. Missing construction data remains visible in the source-notice panel.

The seven default recipes were drafted and source-mapped in the browser. Their front/back geometry, sewn placements, overlays and available POMs were composed for a 14-face browser/parser matrix. Eight faces returned revision-checked SVG that parsed in Chromium; six faces were correctly withheld with `TEXT_COLLISION`: both Polo faces, both Woven-shirt faces and both Trouser faces. Dense mark and POM layout needs actual-metric reflow before those views can be shown. This output matrix is a renderer integration harness, not the live product flow; Slice 272 owns product integration, and Slice 273 owns the measured default-label reflow.

The retained visual sample is a semantic renderer fixture rather than a sewn or recipe-complete garment. It demonstrates centimeters, silhouette fill, construction mark, closure mark, annotation, POM leader, visible source notice and actual browser text bounds. See [sample screenshot](S271-browser-sample.png), [SVG](S271-browser-sample.svg), [measured browser record](S271-browser-sample.json), and the [seven-recipe front/back matrix](S271-browser-recipe-matrix.json).
