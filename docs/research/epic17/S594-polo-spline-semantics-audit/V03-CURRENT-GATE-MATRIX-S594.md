## Bounded continuation

Autodesk's DXF specification distinguishes closed, periodic, rational, planar
and linear bits. Its API distinguishes closed from periodic splines and
describes periodic knot/control-count conventions. Independent de Boor
evaluation gives zero source residual for both tested nonperiodic encodings;
the different group-70 closed bit did not change the mathematical curve.
Thus another closed-bit-only SPLINE trial is unsupported. S595 may prepare a
proper periodic degree-1 encoding only if its exact periodic basis and source
geometry are first independently verified; CLO import/export is then one
bounded receiver test, and a failure retains the five-piece hold. The generic
Autodesk references do not prove CLO interpretation or industrial apparel
conformance. Every all-seven and V03 gate remains.
