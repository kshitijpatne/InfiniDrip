## Authority, source facts, and approved view convention

The maintainer's 2026-10-01 S321 decisions, recorded in `docs/PROJECT-DECISIONS.md`, authorize the following view-only station transfer. These are product/view conventions, not source claims that an exterior edge has a physical notch.

- **Polo outer stand:** the shared `backCollar`/`frontCollar` endpoint is a directly encoded exterior station. Use this exact junction; do not interpolate it.
- **Polo upper and under collars:** compute the source base fraction `r = length(backCollarBase)/(length(backCollarBase)+length(frontCollarBase))` from CB toward CF on each current piece. Transfer normalized arclength `r` onto each unmarked `outer` edge from its CB endpoint toward CF. Map the CF-to-station segment to FRONT_FLAT and station-to-CB segment to BACK_FLAT.
- **Woven outer stand:** compute `r = back neckline length / (back neckline length + front neckline length)`, using the exact ordered neckline interfaces in the live Block (back component is the source-selected back or yoke). Transfer normalized arclength `r` from CB toward CF onto exterior `outerStand.collar`.
- **Woven upper and under collars:** transfer the same sourced neckline fraction onto each piece's `outer` edge from CB toward CF. Keep the source-declared center-back fold axes and authored upper/under layer order.
- No station is drawn as a stitch, mark, or cut line. Do not alter source edges, stitch graph, geometry, or DXF/export behavior. Resolve every transfer from the exact live Block/revision; never reuse default coordinates.
