routes actually tried are vendor-specific empirical targets, not standards
conformance claims. The named route with the latest actual result is

trial use and local DXF handling; it does **not** prove normative
ANSI/AAMA/ASTM conformance or make the measured result pass. OpenCAD Studio
v2026.40.1 R14 is a local generic-DXF route, not an industrial apparel
receiver/profile. GetonAgain Garment CAD V2024.1 is only a candidate: public
first-party material found so far does not establish trial rights for this
product-development evaluation or local processing of exact DXF exchange;
explicit authorization to acquire/install/run it is also absent. No G04
fixture may enter it under the current state.
