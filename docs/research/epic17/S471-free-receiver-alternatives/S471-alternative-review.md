# Free CAD alternatives review — Slice 471

## Result

No reviewed alternative is both a suitable V03 receiver and within the current
G04 scope. The result does not establish compatibility for any application.

| Candidate | Evidence and limitation | Disposition for G04 V03 |
|---|---|---|
| Seamly2D | The official project repository lists GPLv3+ and Windows 10/11 64-bit. In the project's user forum, maintainers confirm Seamly2D has no DXF import; its parametric drafts are not opened from DXF. | Not a receiver for S463 patterns, despite being free/local and supporting this Windows host. |
| OpenMarker | The official Apache-2.0 project describes itself as local/offline and imports ET CAD-style INSERT DXF plus flat modelspace fallback. It says it is not production-ready and its export flow is still planned. | Not a round-trip receiver yet. Its present import/layout ability cannot establish exchange output. |
| garment.dev | The official site claims AAMA/ASTM import/export and validation against 34 production files. It also says access is by invite and patterns live in a shared account-backed browser library. | Hosted service; expressly outside admitted G04 scope. Do not request access or transmit even synthetic fixtures for this Epic. |
| Richpeace Garment CAD V8 Free English | Its official page lists only Windows XP/7/8/10, but links the manual that documents AAMA/ASTM import and ASTM export. | Still the strongest documented exchange candidate, but Windows 11 support and exact installed build remain unverified. Owner must decide whether to attempt a normal install; stop on failure/instability. |

The search found no free online receiver that can be used under G04's local-
processing and no-hosted-service boundaries. A web-based file viewer or DXF
parser can aid visual inspection but cannot replace the required receiver
import/export round trip.

## Source basis

- Seamly2D [official repository](https://github.com/fashionfreedom/seamly2d)
  identifies the GPLv3+ project and Windows 10/11 platform. The project's
  [DXF import discussion](https://forum.seamly.io/t/import-files/8595) confirms
  there is no DXF import function.
- OpenMarker [official repository](https://github.com/Weilei424/openmarker)
  documents local operation, current DXF import scope, non-production status,
  and export as planned.
- garment.dev [official site](https://garment.dev/) describes its AAMA/ASTM
  import/export claims, invite access, free drafting surface, and shared
  account-backed browser library.
- Richpeace [official V8 Free English listing](https://www.richpeace.com/garment_cad-show-443.html)
  lists the OS support range; its exchange evidence is detailed in S468/S470.

## Scope and next action

No candidate is selected, and no rights, profile, acceptance, software, or
fixture state changed. Preserve V03 rights review, exact-version, local
processing, representative simple/complex/multi-size/negative-fixture and
observed round-trip gates. The next useful action still depends on owner access
to an exact lawful receiver/build. If the owner tries Richpeace V8, use the
standard installer only and perform S469's preflight before any fixture opens.
