- **Source finding:** `Piece.onFold` records how a pattern piece is cut; it does not define which contour runs belong in a finished front/back view, how many garment instances a role represents, or how a surface boundary should be partitioned. The Polo collar base has centre-back/shoulder/centre-front landmarks, but the outer collar edge has no source landmark at the front/back visibility split. The Woven-shirt stand/collar sources have a centre-back fold but no centre-front/shoulder partition on their exterior edges. Stitch ordering can identify the joined neckline length segments; it cannot prove which complete exterior contour is visible from one face. A view-specific partition would otherwise invent a split point or suppress a source edge without evidence.
