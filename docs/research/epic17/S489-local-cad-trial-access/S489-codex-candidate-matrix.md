# S489 — StyleCAD and Optitex no-cost local-access matrix

Reviewed 2026-10-08 against official publisher pages. S464 already established
neither product was installed; S486/S488 already documented broad format and
candidate facts. This matrix addresses only whether a no-cost local evaluation
path can open the next V03 gate. A web demo, viewer, or downloadable installer
does not by itself grant a local editable license.

| Gate | StyleCAD | Optitex |
|---|---|---|
| No-cost local license | **Not established.** PDS Pattern Expert offers “Request an Online Demo”; its pricing page lists the full StyleCAD PE/Split systems with DXF Import/Export and “Get a Quote.” No public free local trial/license is documented on these sources. Do not infer that a trial is impossible; the publisher has not documented one here. | **Not established for PDS.** The official O/26.1 customer portal advertises a full PDS 2D/3D install and separately describes free viewers. It does not identify the PDS installer as a free license. The explicit free-trial provision found is only for OPTINEDCloud Subscription Services, a SaaS product. |
| Product distinction | **Online demo only is documented.** No public page establishes that the demo provisions editable software or a transferable/local receiver. | **Cloud trial is out of scope.** OPTINEDCloud GTC defines the trial product as internet-accessible SaaS used to upload, share, view, or process apparel files; local-only handling is therefore not established and file transfer is intrinsic to the service. The 2D viewer is described as supporting viewing PDS/Marker files, not as a pattern authoring/export receiver. |
| Apparel profile directions | Official FAQ documents AAMA DXF among import formats. The pricing page lists generic DXF Import/Export, but the sources do not establish AAMA/ASTM output behavior for a no-cost local edition. | Official bundle page documents standard-format import including AAMA, ASTM, and DXF. General PDS materials promise exchange across standard CAD formats; an exact no-cost local build/profile output path is not documented by the access pages. |
| Exact build and Windows | **Unresolved for a no-cost local demo.** No build or install grant is specified on the demo page. | Portal lists O/26.1 downloads, but access/version listing is not an activated license or rights grant. Current OS support is not established here for a no-cost path. |
| Round-trip, grades, invalid input | No receiver was available to test. | No receiver was available to test. |
| Decision | **Does not clear V03 Gate 0.** A quote and online demo cannot be treated as free local licensed access. | **Does not clear V03 Gate 0.** The local PDS license is not shown as no-cost; the documented free-trial branch is hosted and processes submitted files, so cannot satisfy G04's local-only receiver boundary. |

## Primary sources

- StyleCAD [PDS Pattern Expert](https://www.stylecad.com/pds-pattern-expert):
  requests an online demo, without describing a local trial license.
- StyleCAD [Pricing](https://www.stylecad.com/pricing): identifies the PE and
  Split PE/PG systems, generic DXF Import/Export, optional ecosystem converters,
  and quote-based pricing.
- StyleCAD [FAQ](https://www.stylecad.com/faq): identifies AAMA DXF as an
  import format; import support does not establish an enabled no-cost export.
- Optitex [apparel bundles](https://optitex.com/fashion-apparel-solutions-bundles/):
  lists PDS product tiers and standard-format import including AAMA/ASTM/DXF.
- Optitex [O/26.1 customer downloads](https://my.optitex.com/): lists the full
  install separately from free viewers; the portal does not document a free
  PDS license.
- Optitex [OPTINEDCloud Services Master Agreement](https://optitex.com/optinedcloud-gtc/):
  §§1 and FREE TRIAL define the trial as internet SaaS that uploads, shares,
  views, or processes apparel files; this is not a local PDS trial.

No product was installed or run; no account/trial was accepted, no vendor was
contacted, and no files/fixtures were accessed or transferred. Keep all V03
rights, local-handling, exact-profile, round-trip, grading, and malformed-input
gates unchanged.
